A future sandbox service module is intended to use **Elastic License 2.0** with

module or ELv2-licensed code is shipped today. ELv2 limits offering the software
as a hosted or managed service where users receive access to a substantial set
of its functionality; it is source available rather than OSI open source.
[ELv2 terms](https://www.elastic.co/licensing/elastic-license),
[ELv2 FAQ](https://www.elastic.co/licensing/elastic-license/faq).

AGPL does not prohibit competing hosting; its network provisions require offering
corresponding source for modified versions to their remote users. That is a
different tradeoff from ELv2's managed-service limitation.
[AGPL section 13](https://www.gnu.org/licenses/agpl-3.0.html#section13).
